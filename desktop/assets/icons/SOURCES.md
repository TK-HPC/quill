# Icons

Original Stroke Rounded icon geometry from [Hugeicons](https://hugeicons.com), `@hugeicons/core-free-icons` version 4.4.0 (MIT; license included). The published icon element data is serialized as standalone SVG for GTK. Original paths and rounded joins/caps are preserved; strokes are adjusted to 2.1 units (2.4 for navigation) for compact desktop legibility, with Quill black as currentColor. No icon library runtime or network calls.

- `home.svg`: `DashboardSquare01Icon`
- `history.svg`: `Clock01Icon`
- `dictionary.svg`: `Book02Icon`
- `settings.svg`: `Setting07Icon`
- `microphone.svg`: `Mic01Icon`
- `close.svg`: `Cancel01Icon`
- `copy.svg`: `Copy01Icon`
