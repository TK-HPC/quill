# Bundled fonts

DM Sans, DM Mono, and Newsreader from [Google Fonts](https://github.com/google/fonts/tree/5bd87dfc525c8a0d1d8529d3684716e00c3fc59a/ofl), revision `5bd87dfc525c8a0d1d8529d3684716e00c3fc59a`. Original font files; each family’s SIL Open Font License is included alongside it. Loaded only for Quill through Pango, without system-wide installation or runtime downloads.
